## 3. Ключевые архитектурные инварианты

1. **Изоляция окружения:** Все зависимости и виртуальные окружения изолированы внутри данного подпроекта. Запрещено использовать глобальные интерпретаторы.
2. **Верификация изменений:** Любое изменение перед коммитом обязано проходить штатную верификацию:
   ```powershell
   pwsh -ExecutionPolicy Bypass -File scripts/verify.ps1 -Subproject landing-most
   ```
3. **Безопасность секретов:** Пароли, токены API и боевые доступы берутся строго из переменных окружения (`.env`), хардкод запрещён.

## 4. Рабочие сценарии

### Сценарий: Локальная разработка и тестирование
1. Перейти в каталог проекта:
   ```powershell
   cd projects/landing-most
   ```
2. Запустить локальную сборку / тесты:
   ```powershell
   npm run lint; npm run build
   ```
